# ISNAD website (static)
Plain HTML/CSS/JS, no build step. Pages: `index.html` (landing, Tamil/English toggle) and `privacy.html` (Play Store privacy-policy link).

Deploy on Cloudflare Pages: Create project > Connect to Git > this repo > Build command: (none) > Build output directory: `site`.
Before going live: replace `FILL_IN_YOUR_EMAIL` in `index.html` and `privacy.html`, and set the Google Play button link once the listing exists.
Do not put the APK or the web version of the app here (content licences; Pages has a 25 MB file limit).
